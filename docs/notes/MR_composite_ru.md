# Множество M_R = R⊗R̄ в дифференциальном разложении

Тред «Множество M_R = R⊗R̄». Скрипты: `scripts/mr_composite_check.py`, `scripts/mr_channel_factors.py`, `scripts/mr_21_channels.py` (ветка `claude/project-thread-46t8e7`), копии вывода лежат рядом.
Обозначения статьи: D_n = {Aq^n}, {x} = x − 1/x, [n] = {q^n}/{q}, ε = {q}.

## Коротко

1. **Противопоставление «M=R для симметрических / M=R⊗R̄ для общих» действительно ложное.** Формула II (интерполяционная, `methods/interpolation.py`) записывает H_R для любого R как сумму по каналам R⊗R̄:
   Z_R^c = d_c · Φ_c(R),  Φ_c(R) = Σ_X E_{cX} (χ̂_X(R) − 1),
   где d_c — квантовая размерность композита c = [λ, μ], χ̂_X(R) — нормированное зацепление Хопфа R с композитом X, E — универсальная унитреугольная матрица. Для R = [r] каналы — только синглеты [j, j̄], и формула II **в точности** даёт симметрическое DE (в нормировке G^{4_1} = 1, т. е. с дефект-нулевым множителем в Z):
   Z^{[j]}_{[r]} = [r]!/([j]![r−j]!) · ∏_{i=0}^{j−1} D_{r+i} D_{i−1}.
   Проверено точно (рациональные функции A, q) для j ≤ 4, r ≤ 6. «X ⊆ R» — просто нумерация синглетов [X, X̄]; для прямоугольных R произведение R⊗R̄ = ⊕_{X⊆R}[X, X̄] без кратностей, поэтому множества совпадают. Различие появляется только у непрямоугольных R: пары {Z, Z'} и кратности.

2. **Z_[1] и Adj — точное утверждение.** Z_{[1]}^{[1]} = D_1 D_{−1} = ε²·dim_q(Adj). Для любого R канал Adj даёт
   Z_R^{Adj} = d_Adj · (χ̂_Adj(R) − 1) = Σ_{b∈R} D_{c_b+h_b} D_{c_b−h_b}
   (c — содержание, h — длина крюка клетки; проверено на всех 29 диаграммах |R| ≤ 6). То есть каждая клетка R вносит «Adj-фактор» {A'q'}{A'/q'} при A' = Aq^{c_b}, q' = q^{h_b}. Для R = [r] сумма сворачивается в [r] D_r D_{−1}.

3. **Диаграмма [k, k̄] и «два столбца».** Размерность композита
   d_{[k,k̄]} = D_{−1} (D_0⋯D_{k−2})² D_{2k−1} / ([k]! ε^k)²
   содержит дефект-нулевое произведение **дважды**. Подсчёт крюков и содержаний на диаграмме (r+k, r^{N−2}, r−k): первая строка даёт D_0⋯D_{k−2}·D_{2k−1}, а содержания k клеток «сверху» (D_r … D_{r+k−1}) сокращаются с крюками полных столбцов, то есть в размерности их нет. Остальная часть (тело R̄ с усечённым концом) даёт D_{−1}D_0⋯D_{k−2}. Множитель Хопфа
   Φ_k(r) = [r]!/([k]![r−k]!) · ([k]! ε^k)² ∏_{i<k} D_{r+i} / (D_{2k−1} ∏_{i<k−1} D_i)
   заменяет вклад первой строки на столбец сверху ∏D_{r+i} и добавляет q-биномиал. Итог:
   Z^{[k]}_{[r]} = [q-биномиал: усечённый конец] · [∏_{i=1}^{k} {Aq^{r+i−1}}: столбец сверху] · [∏_{i=1}^{k} {Aq^{i−2}}: тело].

4. **Где «концевое» ∏{Aq^{i−1}} и что съедает дефект.** Точнее всего видно в прямоугольном случае (формула закреплена в `tests/test_interpolation.py`):
   Z_{[r^s]}^{[μ,μ]} = ∏_{b∈μ} D_{r+c_b} D_{c_b−s} [r−c_b][s+c_b] / [h_b]².
   В sl_N-диаграмме композита (r+μ_1, …, r+μ_s, r^{N−2s}, r−μ_s, …, r−μ_1):
   * D_{r+c} — sl_N-содержания μ, приклеенной справа к R (тот самый «столбец сверху»);
   * [r−c] — содержания клеток, срезанных в конце (усечённый столбец). Они **не зависят от A** и дают q-биномиал, поэтому ∏{Aq^{i−1}} «в конце не видно»;
   * D_{c−s} — содержания μ, поставленной сразу под R, в начало тела R̄. Для s = 1 это D_{−1}D_0⋯D_{k−2}, то есть искомое ∏{Aq^{i−1}};
   * [s+c] — партнёр [r−c] при транспонировании.

   Дефект действует только на этот третий множитель. В нормировке статьи Z_{[r]}^{[j]} = binom·D_{−1}∏D_{r+i}, а G_j ∝ ∏_{i=1}^{k_j} D_{i−1}. Значит:
   * D_{−1} всегда универсален: при A = q (sl_1) H ≡ 1;
   * D_0, …, D_{j−2} (линии A = q^{−m}, m = 0..j−2, супергрупповые gl(1|m+1)) knot-зависимы. Узел «отдаёт» k_j из них, дефект-нулевой — все;
   * столбец сверху ∏D_{r+i} (линии sl-сопряжения) дефект не трогает никогда.

   Интуиция «дефект съедает часть концевого произведения» верна, если под концевым понимать копию μ под R. Это одна из двух копий в d_{[k,k̄]}.

5. **Непрямоугольные R: то же чтение по клеткам** (таблица `channel_factors.tsv`, все синглетные каналы при |R| ≤ 5). Вводим T (μ приклеена справа к R по строкам, клетка (i,j) → (i, R_i+j)) и U (μ под R по столбцам, (i,j) → (R'_j+i, j)). A-зависимая часть Z_R^{[μ,μ]} равна ∏ D по содержаниям T ∪ U во всех каналах кратности 1, где T и U не попадают в одно содержание. Примеры: [2] в [2,1] → D_{−2}D_0·D_2D_3; [3] в [3,1] → D_{−2}D_0D_1·D_3D_4D_5; [11] в [3,1] → D_{−3}D_{−2}·D_0D_3.
   * Если T и U дают одно содержание c (как [2,1] в [2,1]: c = 0 из клетки (2,2)), пара c, c заменяется на c−1, c+1: D_{−3}D_{−2}D_{−1}D_1D_2D_3. Это «отталкивание», иногда каскадное. Общего правила пока нет, это наблюдение.
   * В каналах кратности 2 (например, [2] в [3,1], Adj в [2,1]) Z не факторизуется: формула II видит только след по пространству кратности.

   Сводка по всем 91 синглетному каналу при |R| ≤ 5: 70 каналов кратности 1 факторизуются все. В 52 из них A-зависимая часть **в точности** равна ∏_{T∪U} D. В остальных 18 T и U сталкиваются в одной клетке, и отличие локальное: пара D_a D_b из сталкивающегося отрезка содержаний заменяется на D_{a−1} D_{b+1}, иногда каскадом. Сумма индексов при этом сохраняется. Пример: [4,1] в [4,1], T∪U = {…, 0, 0, 1, 2, …} → {…, −1, 0, 1, 3, …}. 21 канал кратности 2 не факторизуется ни разу.

6. **Проверка на каталоге: переживают ли симметрические G_j переход в каналы [2,1]?** Это и есть содержательная форма вопроса «M_R = R⊗R̄ для всех узлов». Для каждого узла с H_[1], H_[2], H_[1,1], H_[2,1] (2860 узлов) брали G_1, G_2, G_{11} из симметрического (антисимметрического) DE и подставляли в каналы Adj, [2,2̄], [11,11̄] разложения [2,1] с Z формулы II. Остаток должен иметь вид Z^{pair}G_p + Z^{[21]}G_{21}, где Z^{pair} = ε⁴[3]²D_2D_{−2} и Z^{[21]} = D_{±1}D_{±2}D_{±3}.

   Проверка — точная принадлежность идеалу (базис Грёбнера над ℚ[A^±, q^±]), файл `channels_21_catalog.tsv`:
   * у всех 2860 узлов остаток делится на D_2 D_{−2}, как и требует общий множитель Z^{pair} и Z^{[21]};
   * лорановы G_p, G_{21} существуют **ровно у 23 узлов: 18 double braids и 5 нечётных претцелей**, то есть ровно у всех узлов с δ = 0 в каталоге;
   * у остальных 2837 (все с δ > 0) разложение существует, если knot-функциям пары и [21] разрешить простой полюс на D_2 D_{−2}. Полюсов на D_0 недостаточно ни для одного узла: вклад D_0 к этому моменту уже поглощён множителями D_0 в Z^{[2]}, Z^{[11]}.
   * На линиях A = q^{±1} это видно как ровно один лишний множитель [3] в знаменателе: D_{±2}|_{A=q^{±1}} ∝ {q^3}.

   Вывод: симметрические knot-функции G_j без изменений переходят в каналы [j, j̄] представления [2,1], противоречий нет ни на одном узле. Для узлов с ненулевым дефектом непрямоугольная часть несёт полюс на D_{±2}. Это линии A = q^{∓2}, где H_{[2,1]} = H_{[1]} для всех узлов (универсальная редукция). У симметрических R в той же нормировке дефект виден как полюса на D_0, …, D_{j−2}. Значит, для [2,1] «дефектные» линии сдвигаются туда, где R склеивается с меньшей диаграммой, и для δ = 0 полюсов нет вовсе. Это согласуется с тем, что в формуле II полюса D_{±2} у претцелей уже отмечались (F2). Оговорка: тест проверяет существование разложения, а не единственность. Две неизвестные G_p, G_{21} при одном уравнении — слабая проверка, сильнее её делают только найденные полюса.

7. **Почему R⊗R̄ может возникать для любого узла (эвристика, не доказательство).** Любое пересечение — это полуоборот антипараллельной пары, если смотреть «горизонтально» (повернуть картинку на 90°). Поэтому через каждое пересечение любого узла проходит антипараллельное эволюционное семейство K_m: H_R(K_m) = Σ_{X∈R⊗R̄} E_X Λ_X^m с теми же Λ_X, что у twist-узлов. Нули ∏D_{r+i} — склейка Λ_X при sl-сопряжении (свойство (i) статьи), так что они доступны каждому узлу. Для нечётных претцелей «вертикальная» (параллельная) эволюция по ногам даёт R⊗R, а «горизонтальная» по любому пересечению даёт R⊗R̄. DE видит вторую.
